# Chapter planning and maps

The Journey follows 15 walkthrough areas, then free-roam cleanup and optional DLC. These are editorial route checkpoints, not numbered chapters exposed by the game. Selecting a checkpoint changes recommendations only; it never completes achievements.

## Missable classification

The 14 human-enemy combat goals are marked **Missable**. Wildlife, exploration, tombs, and collectible goals are not given the same warning. The guide preserves unfinished combat goals in the final audit, even when a suggested earlier encounter has passed. It never marks a player's achievement permanently lost based only on chapter selection.

Verified tutorial/encounter windows are labeled **Earliest practical window**. Skill-dependent and exploration placements are labeled **Planning window** or **Suggested starting area**. Requirements still depend on bought skills, herbs, equipment, route access, available enemies, and the player's save. No fixed playtime estimate is presented.

Sources:

- [PowerPyx roadmap](https://www.powerpyx.com/shadow-of-the-tomb-raider-trophy-guide-roadmap/): missable classification and specific tutorial unlocks/encounters.
- [XboxAchievements roadmap](https://www.xboxachievements.com/game/shadow-of-the-tomb-raider/guide/): combat cleanup and free-roam distinction.
- [Stella's walkthrough](https://tombraiders.net/stella/shadow.html): area order and repeated Paititi visits.
- [Stella's collectible index](https://tombraiders.net/stella/walks/TR11walk/collectibles.html): annotated region-map destinations.

The notes are concise original planning summaries, not reproduced walkthrough passages. Linked sources provide full routes and platform-specific details. Current platform unlocks are the source of truth.

## Atlas

The bundled offline atlas is an original **route diagram, not to scale**. Its decorative contours are not geographical measurements, and it makes no claims about collectible coordinates.

Detailed game maps load directly from Stella's site in the native Safari viewer inside the app. No third-party map files are bundled or copied into this repository. Their publisher retains attribution and ownership. An internet connection is required for these maps; the original route diagram and achievement plans work offline.

## Appearance

The app uses native navigation stacks, grouped lists, pickers, sheets, search, toolbars, and tab bars so the installed OS supplies its current design. Custom glass controls use the iOS 26+ glass API, with a material fallback on older systems. Semantic colors support System, Light, and Dark appearance without forcing text colors. Standard, dark, and tinted icon variants are generated from the repository's original vector geometry.

[Apple's SwiftUI design updates](https://developer.apple.com/videos/play/wwdc2026/269/) informed the use of system components and restrained glass surfaces. The project is built with the installed Xcode 27 SDK; simulator verification uses the installed iOS 26.5 runtime rather than claiming an untested iOS 27 runtime.
